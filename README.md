# lexcalli
An Anki-inspired language learning app for mastering vocabulary, collocations, and expressions through spaced repetition, active recall, and interactive exercises.

## Development notes

- [Agent instructions](AGENTS.md) — entry point for coding agents.
- [iOS engineering guide](.agents/AGENTS.md) — SwiftUI architecture conventions, skill references, and verification guidance.

## Agent skills

The engineering guide references [SwiftUI Expert](https://github.com/AvdLee/SwiftUI-Agent-Skill) and [Swift Concurrency](https://github.com/AvdLee/Swift-Concurrency-Agent-Skill). Install these skills locally before relying on their instructions.

Run `just skill-update` to update installed skills; review changes before committing.
